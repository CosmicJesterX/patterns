## How to Use This Project

### For New Projects

1. **Identify your pattern needs**
   ```bash
   grep -r "When to Use" playbooks/
   ```

2. **Load the relevant skill**
   ```bash
   skill_view(name='pattern-name')
   ```

3. **Copy the template**
   ```bash
   cp templates/pattern-scaffold.md my-new-project/
   ```

4. **Customize & deploy**
   - Follow the playbook steps
   - Adapt for your context
   - Update project manifest when done

### For AI Agents

When the AI detects:
- "theatrical" + "security" → Load `theatrical-security-honeypots`
- "honeypot" + "education" → Load `theatrical-security-honeypots`
- "progressive" + "learning" → Load `progressive-learning-systems`
- "lore" + "documentation" → Load `living-documentation`
- "persona" + "adapt" → Load `persona-aware-adaptation`

This is **automated pattern injection** — no manual skill loading needed.

## Adding New Patterns

When a new pattern emerges (after completing a project):

1. **Extract the playbook**
   - Document architecture & philosophy
   - List customization points
   - Create templates

2. **Create the skill**
   - skill_manage(action='create', name='new-pattern-name')
   - Reference playbook & templates
   - Add to automated detection

3. **Update this manifest**
   - Add pattern entry
   - Link skill & playbook
   - Document usage examples

4. **Commit to git**
   ```bash
   git add patterns/
   git commit -m "pattern: Add new-pattern-name playbook & skill"
   ```
